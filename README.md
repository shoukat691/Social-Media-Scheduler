# Social-Media-Scheduler

Hey everyone! I am currently building an open-source project—a simple and clean **Social Media Scheduler**. Managing posts across multiple platforms manually can be super tedious and time-consuming, so I wanted to build a tool that brings everything into one unified dashboard.

This project is still under active development, but the core authentication and UI setup are already up and running!


### Tech Stack
To keep things modern, fast, and reliable, I am using the following stack:
* **Frontend:** Next.js (React) + Tailwind CSS 
* **UI Components:** Shadcn UI (for a clean, modern look)
* **Authentication & Database:** Supabase (for secure user management)

---

### Current Status & Features
* [x] Project architecture and folder structure setup.
* [x] Modern Sign-in and Sign-up pages integrated with Supabase Auth.
* [x] Custom UI styling and responsive layout.
* [-] Social media API integrations (Twitter, LinkedIn, Facebook) — (Currently working on this!).
